ここから分かること

  • 1本かけて断られたのはふつう。落ち込む必要はない。
  • ただしこの分母を根性で埋めるのは無理。だから手段を変える（02〜04）。

02

順番を逆にする
「電話→見せる」ではなく「見せる→電話」

いちばん効く改善はここ。ほかを全部飛ばしてもいいくらい重要。

いままで 電話でアポを取る → 訪問してそこで初めてHPを見せる
→ 電話の時点では「よくある営業電話」でしかない
これから 先にHPそのものを届ける → 2日後に「送った件の確認」で電話
→ 電話が営業電話ではなく確認の連絡に変わる

なぜこれが効くのか

  • 一度でも接点があった相手は、まったくの新規より10〜40倍反応する。
  • うちの武器は「もう完成している」こと。これは提案ではなくプレゼントとして渡せる。 人は先に何かをもらうと、返したくなる。だから話を聞く義理が生まれる。
  • 逆に電話で口頭説明した瞬間、この武器はゼロになる。 HPは「見せた瞬間に売れる商品」。電話で説明するのは、料理を電話で味見させようとするのと同じ。
  • 送る道具はもう全部そろっている。営業用リンク集の「提案書」「サイト」「QR」をそのまま使う。
根拠となる数字を見る

紹介・一度接点のある相手（ウォーム）は、完全な新規（コールド）に比べて初回連絡への反応が10〜40倍。返信後の商談化も3〜6倍。

どこから接触するか
電話は「本人に届かない」

お店の電話は、ほぼ確実にパートさん・ホールの人が出る。決まる相手（オーナー）に届かない経路で戦っている。 だから先に紙を届けて、電話はその確認としてかける。出なければ時間帯を変えて、あと二度まで（2026-08-19 に「一度だけ」から改めた）。

  • 宛名は「店長様」ではなくオーナーの実名で書く。開封率が変わる。 名前の調べ方＝Googleクチコミの返信者名／食べログの店主コメント／Instagramのプロフィール／地元の取材記事。
  • 面識ゼロの相手（新規リスト）だけに絞っても、紙は2〜4.4%反応する。メールより桁が違う。
  • ★手紙だけでは、サイトが一度も開かれないことがある。導線がQR1つしかないため。 A4カラー1枚の「ホームページ見本」を必ず同封する（そのお店のページを紙に写したもの）。 2026-08-13、最初の5件の架電で「お宅は何の会社？」と聞かれた。手紙は届いていたが、商品は一度も見られていなかった。

② 訪問（電話でアポを取らず、直接行く）

  • アイドルタイムに、そのお店のHPを開いた状態のスマホ／iPadを持って入る。
  • 第一声は「これ、〇〇さんのお店のホームページです」。説明より先に画面を見せる。
  • その場でQRを出せば、店主のスマホに提案書を移せる。お互い自分の画面を見ながら話す。
  • 電話番号が公開されていないお店は、はじめから訪問の予告で手紙を出している。行く日は当日のSNSで営業を確かめてから。

③ 電話（手紙を出したお店にだけ。時間帯を変えて三度まで）

  • 手紙に「お出になれないときだけ、日を改めてあと二度までおかけいたします。「いらない」のひと言で、そこで終わりにいたします」と書いてある。この約束を破らない。
  • 枠は3つ。1回目 14:00〜16:00／2回目 10:30〜11:30／3回目 16:00〜17:30。 同じ時間に3回かけない——出ない理由はたいてい「その時間が忙しい」なので、同じ1回を3度やっているのと変わらない。
  • ★2026-08-19 に「一度だけ」をやめた理由。飲食店は仕込みで手が離せず、1回で本人が出る確率がもともと低い。 こちらの都合で接触の機会を1回に縛っていた。区切ってさえあれば、回数が1でも3でも受け取り方は変わらない。
  • お話しできたうえで断られたら、そこで終わり。残りの枠は使わない。
  • 言うことは全部1枚に書いてある → 架電スクリプト（第一声・用件・「お宅は何の会社？」の答え・返し方）。
  • 手紙を出した本人がかける。別の者がかけた時点で、手紙の文面が嘘になる。

使わないと決めた手段 ／ SNSのDM

2026-08-12 に検討してやめた。効率だけを見ればDMが有利だが、この売り方とは両立しない。

  • 手紙は宛名を手書きし、切手を貼って「DMに見えないように」出している。次の一手がDMなら「結局DMの会社」になる。
  • DMは返事をしなくても済むので、「回数を区切ってかける・断れば終わり」という手紙の骨格が成立しない。
  • 知らない相手のInstagramのDMはメッセージリクエストに入って気づかれず、Xは設定次第で受け取らない。 届いたかどうかも分からない手段で、区切ってある回数を使い切ることになる。

いつ・誰にかけるか

時間を間違えると、内容がどれだけ良くても永久にその店を失う。

電話をかけていい時間

11:00–14:00絶対NG／ランチで手一杯
13:00–14:00避ける／片付けが残っている
14:00–16:00◎ ここに全振りする
16:00–17:00仕込みが佳境。ギリギリ可
17:00–21:00絶対NG／かけた時点で心証が最悪
  • 14〜16時＝飲食店営業のゴールデンタイム。ランチが終わって仕込み中、客はほぼいない。
  • 定休日の前日の夕方と月曜も狙い目。 週末の売上を見て「今月どうしよう」と考えているタイミング。
  • それ以外の時間は電話をやめて、訪問・手紙にまわす。

誰を出してもらうか

NG 「オーナー様はいらっしゃいますか？」
→ 営業だとバレて取り次いでもらえない
OK 「〇〇さん、お願いできますか？」
→ 名前で指名する。知り合いに聞こえるので取次ぎ率が上がる
  • かける前に必ず名前を調べる。Googleクチコミの返信・Instagram・食べログの店主コメントに出ている。
根拠となる数字を見る

14時〜16時のアイドルタイムは「飲食店営業のゴールデンタイム」と呼ばれ、ここに集中するだけで接触率が大きく改善する。11〜14時／17〜21時は電話に出る余裕がゼロ。13時台はランチの片付けが残るため避ける。

05

電話で何て言うか
「アポをください」と言わない

売り込みだと分かった瞬間に切られる。だから時間を求めず、確認を求める。

NG 「ホームページ制作のご提案でお電話しました。
一度お時間をいただけませんでしょうか」
→ 相手に「時間」を要求している。断る理由しかない
OK 「お忙しいところ、失礼いたします。
先日お手紙と一緒に、勝手ながら〔店名〕さんのホームページを作ってお送りした者です。
（古河市で飲食店のホームページを作っております、creative works+ の〇〇と申します）
本日は、営業時間と定休日に間違いがないか、そこだけ確認させていただきたくお電話しました。1分で終わります」
→ 相手に「事実確認」を求めている。断る理由がない
  • ★会社名から始めない。会社名は3文目。名乗りから入ると、用件を聞く前に「業者の電話」と分かって切られる。
  • ★「いかがでしょうか」と聞かない。手紙で「いらないとおっしゃれば終わり」と断り文句を先に渡してある。聞けばその言葉を使わせるだけになる。
  • ★「作ってしまいまして」と言わない。何十時間もかけた仕事が、軽い仕事に聞こえる（手紙の文面でも禁止している）。
  • 言い回しは全部1枚にしてある → 架電スクリプト。電話の前に開く。

この言い方が効く理由

  • 自分の店の情報が間違っていて困る人はいない。だから「見る」しか選択肢がない。
  • 「もう作った」で相手の中に「見たい」が生まれる。
  • アポを求めていないので、断りようがない。アポは見てもらったあとに自然に出る。

「お宅は何の会社？」と聞かれたら（20秒）

売り込みで終えず、最後は質問で返す 古河市で、飲食店のホームページだけを作っております。
〔店名〕さんの公式のページが見当たらず、勝手ながら先に作ってお送りしました。
ご覧いただくのも、間違いを教えていただくのも無料です。

—— お手紙は届いておりましたでしょうか。 ポイント：言い切って黙ると、相手はその間に「で、何を売りたいのか」を組み立てる。質問で返せば、次に話すのは相手になる。

手紙の文面は、ここではなく専用の決まりに従う

  • 手紙の店ごとの一段落（差し込み①）には禁止語がある（「〜のですね」「珍しい」「作ってしまいました」など）。 初対面の相手の郵便受けに入る紙で距離を詰めた口調を使うと、中身の真心まで嘘に見える。2026-08-02 に全16通を書き直した。
  • 営業マンが手紙を書くことはない。差し込み文・宛名・同封物はこちらで用意して渡す。

刺さる言い方＝「得」ではなく「損」で言う

弱い 「HPがあると集客が増えます」
強い 「いま『店名』で検索したお客様が、公式の情報が無いので他のお店に流れています」
  • 人は得より損を約2.25倍強く感じる。得の話より損の話のほうが動く。
  • 根拠も言える。お店探しでいちばん信頼されるのはGoogleマップ30.4%、次が食べログ24.4%。 Googleで店名を調べた人が最後に見るのが公式HP。そこが空白＝取りこぼし。
根拠となる数字を見る

損失回避：カーネマン＆トベルスキーのプロスペクト理論。同じ額でも、失ったときの痛みは得たときの喜びの約2.25倍。

06

お金の話し方
「安さ」で押さない

初期15万円（月々に分けるなら月15,000円×10回。どちらも同額）・月5,000円は本当に安い。でも安さで押すと安く見られる。比べる相手を変える。

① 月5,000円が何のお金かを、先に4つで言う

そのまま言える一言 「月々の5,000円は、次の4つです。
①ホームページの書き換え（月1回まで）。②Googleの地図に出るお店の欄へ、写真と近況を毎月こちらで入れます。
③クチコミへのお返事の文をお作りします。④地図が何回見られて、お電話が何回押されたか、毎月ご報告します。
②から④は、ご依頼がない月もこちらから毎月やります。」 ポイント：「更新代行」と言わない。何もない月がある言い方に聞こえ、月額そのものを疑われる。 競合には月9,800円のサブスク型（プロパゲート等）がある。金額では負けるので、中身と、サイトが誰のものかで比べる （向こうは解約するとサイトが消え、自分のものになるのは36か月後）。
絶対に言わない 「お客様が増えます」「検索で1位になります」「〇人来ればもとが取れます」
→ 根拠なく効果を言い切ると景品表示法（優良誤認）に触れます。お約束できるのは毎月やる作業だけ。 言い方の正は Claude/docs/サービスの定義.md

② グルメサイトの費用と並べる

そのまま言える一言 「20名の宴会を1件、自分のホームページから直接取れたら、それだけで4,000円浮きます。
月に2件で、うちの月額はもう消えます。」 ポイント：店主が電卓を叩ける言い方にする。抽象的な「集客が増える」は動かない。

③ 補助金を必ず出す

  • 小規模事業者持続化補助金の第20回（2026年5月27日〜）から、 「ウェブ関連費は申請額の4分の1まで」という縛りが撤廃された。ウェブサイト関連費は上限30万円。
  • ただしウェブ費だけの単独申請はできない。チラシ・看板・のぼりなどと組み合わせる必要がある。 ここまで正確に言えると「詳しい人」に見える。うろ覚えで言うと逆効果なので、この2行を暗記する。
  • 申請書類の下書きを手伝えると、それ自体が他社との差になる。

④「5年で45万は高い」と言われたら

やってはいけない：日割りにして小さく見せる 「1日たった164円です」
→ これは金額を小さく見せる手です。総額を正直に出したからこそ信用された相手に、 その直後に小細工を出すと、得た信用をその場で失います。 こちらから先に日割りを出さない。相手が自分から「月々ならいける」と言ったときだけ使う
正解：数字は変えず、比べる相手を変える 「45万、確かに安くはありません。私も安いとは申しません。
問題は、その45万を何と比べるかだと思っています。」
→ グルメサイトの有料掲載は月1万〜10万円。5年なら60万〜600万円。しかも予約1人ごとの手数料が別
さらに強い：その店の実数で計算する 「〇〇さんのお店、宴会は何名様くらいが多いですか？」→「20名くらい」
「食べログのネット予約だと、20名で4,000円の手数料です。年に何件くらいありますか？」
→ 一般論をやめて、その場で相手に数字を言わせる。自分で言った数字は否定できません

★「〇人来ればペイします」は書かない・言わない

  • 効果の約束になります。来なかったときに「話が違う」になる。根拠のない数字なら景品表示法の問題にもなり得ます
  • その数字が商談の争点になります。 レビューした店主は「ホームページを見て来る客が、うちに何人来るんですか」を、電話で真っ先に問い詰めたい質問に挙げていました。自分から答えられない土俵に上がることになります。
  • 「実績はまだ少ない」と正直に書いた手紙と矛盾します。実績が無いのに、なぜ人数が分かるのか
代わりに：約束できないことを先に言う 「新しいお客様が何人来るかは、私には約束できません。約束したら嘘になります。
ただ、いま起きていることなら、その場でお見せできます。」
→ 店主のスマホでGoogleビジネスプロフィールを開き、「検索された回数」を一緒に見る。 これは予測ではなく実データで、しかも店主自身のアカウントで確認できます。
「この〇回のうち、何人かは公式のページを探しています。いま、そこには何もありません。」

仕組みにする

  • 紹介料を決めておく。例＝紹介1件成約で月額を数ヶ月無料、または現金1万円。 15万円の案件が4倍の確率で取れるなら、圧倒的に安い投資。
  • 酒屋・食材卸との提携。彼らは毎週何十軒も回っていて、全店主と顔見知り。 1人と組めば、その人のルート全部が見込み客になる。

写真の注意
ここを突かれると一発で終わる

サイトの写真は食べログなどから取り込んだ「仮」の写真です。これを黙っていると詐欺師に見えます。

起きること 「うちの写真を勝手に使ってるのか？」
→ クチコミの写真は撮った一般のお客様のもので、お店のものですらないことが多い
対策：見せる前に自分から言う 「写真はいまのところ仮です。
ご契約いただいたら、こちらで撮り直して差し替えます。」
  • 先に自分から言えば誠実さになる。後から突かれると詐欺師になる。順番が全て。
  • むしろ「撮影込み」を売りにすると、15万円の価値が跳ね上がる。
  • ロゴ・店名の表記ミス、営業時間のズレも同じ。「間違っていたら教えてください」を先に言う。
