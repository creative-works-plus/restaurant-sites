## 落とした写真と理由（主なもの）

- **公式Instagramの御膳シリーズ5本（麦とろ御膳・静膳・桃御膳・花御膳・小町膳）**
  … 店主が作り込んだ最良の写真だが、**画像そのものに「1,780円（税込）」等の価格と品名の吹き出しが焼き込まれている**。この店は2026年4月以降の価格が取れず**サイトに価格を一切載せない**方針なので、そのままでは使えない。トリミングでも文字が消えない（矢印つきの品名ラベルが皿の上に重なっている）。**代わりに同じ御膳を食べログの実写から3枚採った。**
  → ただし**商談資料としては最良の裏づけ**なので、`/private/tmp/.../scratchpad/raw/` に原本を残してある。オーナーに「この写真の文字を外したものをHPに載せたい」と頼めば即解決する。
- **`黒ごまプリン`（Instagram）** … 同じく「350円（税込）」が焼き込まれている
- **2階の大宴会場の写真（食べログ「100名までの大宴会可能」）** … 実体は**宴会コースの案内の貼り紙**で、部屋は写っていない。価格も入っている
- **店内メニュー冊子11枚・グランドメニュー・ドリンクメニュー表紙** … 価格が読める
- **決済方法の掲示／PayPayの支払い画面** … 掲示物・スクリーンショットで店の絵にならない
- **雑木林越しの外観（2015年1月）** … 冬枯れで暗いうえ、**駐車中の車のナンバープレートが写り込む**
- **カウンターの別カット2枚** … 客の足元・後頭部が入る
- **通路とレジのカット** … レジに人物が写る
- **日本酒の棚** … 「カキフライ 530円」の値札が読める
- **コーヒー12枚・空の器・紙ナプキン・石の置物単体** … 店の魅力に効かない
- **2015年撮影の料理20枚前後**（うな重・和風ハンバーグ定食・一人鍋など） … 10年前で器も盛りも今と違う。ただし**うな重・一人鍋は今もメニューにある**ので、必要になれば `scratchpad/raw/tb/` から拾える
- **食べログの写真一覧に混ざる他店の「おすすめ」画像10枚** … 三春駒・桃花・うなぎ川松ほか。**取り込み時に除外済み**

| 箸袋 | **白地に緑の文字**で「むぎとろ・手打そば 静 しづか」 |

→ **緑（看板の彫り文字）＋ 生成り・クリーム（外壁）＋ 朱（器）**が店の実際の3色。
とろろの白、麦飯の淡い茶、器の朱がよく効くので、**背景は暗く落とさず、生成り〜白に寄せたほうが料理が立つ**。
